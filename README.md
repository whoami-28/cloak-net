## 🕶️ О проекте CloakNet

**CloakNet** (от англ. *Cloak* — мантия скрытности / невидимость и *Net* — зашифрованная кибер-сеть) — это современное, легкое и полностью независимое расширение для браузера Chrome, разработанное для личного использования.

Вам не нужно покупать дорогостоящие подписки на коммерческие сервисы: расширение работает как с официальным бесплатным туннелем **Cloudflare WARP**, так и с любыми вашими персональными **SOCKS5 / HTTPS** прокси и бессерверными **Cloudflare Workers**.

## ✨ Ключевые возможности

### 🛡️ Стелс-маскировка и Премиальный дизайн
- **Эстетика полированного металла и карбона**: Глубокие графитовые градиенты, фаски из холодного титана и фактура углеродной ткани.
- **Генератор маскировки (Power Dial)**: Центральный управляющий диск со световой индикацией режимов:
  - 🟢 **МАСКИРОВКА АКТИВНА (CLOAKED)**: трафик зашифрован, стелс-аура и таймер сессии.
  - ⚫ **МАСКИРОВКА ОТКЛЮЧЕНА (EXPOSED)**: открытый трафик провайдера.
  - 🟡 **АКТИВАЦИЯ МАСКИРОВКИ**: переходный режим установки защищенного канала.
- **Интерактивные локации**: Нидерланды 🇳🇱, США 🇺🇸, Германия 🇩🇪, Великобритания 🇬🇧, Сингапур 🇸🇬, Франция 🇫🇷, Канада 🇨🇦, Япония 🇯🇵 и авто-выбор Cloudflare Edge.

### ⚡ Три режима подключения (Zero-Server Architecture)
1. **Cloudflare WARP (SOCKS5 127.0.0.1:40000) — Рекомендуется**:
   - Работает на официальном бесплатном туннеле Cloudflare.
   - Поддерживает гигабитную скорость, любые HTTPS-сайты и потоковое видео (YouTube, Wikipedia, соцсети).
2. **Свой SOCKS5 / HTTPS / HTTP прокси**:
   - Подключение любого персонального или публичного сервера с авторизацией по логину и паролю.
3. **Cloudflare Worker (Edge Proxy)**:
   - Собственный бессерверный скрипт в Cloudflare Workers (100k запросов/день бесплатно).

### 🔒 Защита приватности и Smart Bypass
- **WebRTC IP Leak Protection**: Безопасная политика `default_public_interface_only` надежно скрывает локальные LAN-адреса (192.168.x.x), но не глушит протокол UDP/QUIC (благодаря чему поиск Google и YouTube работают молниеносно).
- **Прямой доступ к поиску (Smart Search Bypass)**: Поисковые запросы (Google, Yandex, Bing) идут напрямую на максимальной скорости вашего провайдера — без капчи, проверки на робота и задержек.
- **Split Tunneling (Исключения)**: Сайты банков, Госуслуги, Кинопоиск и локальные адреса открываются напрямую в обход туннеля (с поддержкой IDN / Punycode кириллических доменов).
- **In-Window интерфейс**: Настройки и выбор локаций открываются внутри окна расширения без переходов на отдельные вкладки.

## 🚀 Быстрый старт и установка в Chrome

1. Склонируйте репозиторий или скачайте архив:
   ```bash
   git clone https://github.com/whoami-28/cloak-net.git
   ```
2. Откройте Google Chrome и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку проекта `CloakNet`.
5. Закрепите значок **CloakNet** на панели расширений Chrome.

## ⚙️ Настройка источников прокси

### Вариант 1: Использование с Cloudflare WARP (Бесплатно, 1 клик)
1. Установите бесплатный клиент [Cloudflare 1.1.1.1 (WARP)](https://1.1.1.1/) для Windows/Mac/Linux.
2. Включите в клиенте режим прокси:
   ```bash
   warp-cli mode proxy
   warp-cli connect
   ```
   *(Клиент поднимет локальный защищенный шлюз SOCKS5 на `127.0.0.1:40000`).*
3. В расширении CloakNet откройте настройки (шестерёнка) -> выберите **⚡ WARP (SOCKS5)** -> нажмите **Сохранить**.
4. Нажмите центральную кнопку питания — маскировка активна!

### Вариант 2: Использование своего SOCKS5 / HTTPS сервера
1. В окне расширения нажмите иконку **Настроек**.
2. Перейдите на вкладку **🌐 Свой прокси**.
3. Укажите протокол (`SOCKS5` или `HTTPS`), хост/IP, порт и данные авторизации (если требуются).
4. Нажмите **«Проверить прокси»** и сохраните настройки.

### Вариант 3: Использование Cloudflare Worker
Подробное пошаговое руководство по бесплатному развертыванию бессерверного прокси в Cloudflare Workers за 2 минуты описано в файле [`server/README.md`](server/README.md).

## 📁 Структура проекта

```text
cloak-net/
├── manifest.json              # Chrome Manifest V3 конфигурация
├── popup/
│   ├── popup.html             # Адаптивный кокпит расширения (In-Window Views)
│   ├── popup.css              # Стили в темных титановых и карбоновых тонах
│   └── popup.js               # Контроллер навигации, таймер, пинг и IP
├── background/
│   ├── service-worker.js      # Фоновое ядро, авторизация и бейджи
│   ├── proxy-engine.js        # Генератор PAC-скриптов, Punycode и Split Tunneling
│   └── webrtc-blocker.js      # Защита от утечки IP через WebRTC
├── shared/
│   ├── config.js              # Дефолтные настройки и схема параметров
│   ├── locations.js           # Каталог стран, регионов и дата-центров
│   └── storage.js             # Асинхронный адаптер chrome.storage.local
├── server/
│   ├── cloudflare-worker.js   # Готовый бекенд Edge Proxy для Cloudflare
│   └── README.md              # Инструкция по деплою воркера за 2 минуты
├── icons/                     # Фирменные векторные и растровые ассеты
│   ├── cloaknet-logo.svg      # Векторный логотип мантии-невидимки с кибер-сеткой
│   └── flags/                 # SVG флаги мировых локаций
└── scripts/                   # Утилиты генерации иконок и ассетов
```
